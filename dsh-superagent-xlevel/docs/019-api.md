# API local

Nivel 1 — fundación arquitectónica. Lo marcado como referencia funciona en local y no simula un proveedor externo.

## Rutas

`GET /health`, `GET /v1/profiles`, `GET /v1/modules`, `POST /v1/runs`. El cuerpo de runs exige `objective`. Un perfil desconocido responde 400.

El servidor escucha en 127.0.0.1 y el puerto `DSH_PORT` (8787 por defecto). No es el puerto de la interfaz de este entorno.

## HTTP local

`node --experimental-strip-types src/cli/index.ts serve` abre `127.0.0.1:8787`, o el puerto de `SMITH_PORT`. `POST /v1/runs` acepta `{ "objective", "profileId" }`. El perfil tiene que ser uno de los seis. La respuesta es el informe del ciclo, no un stream de un modelo.

`GET` de salud y de perfiles sale del mismo proceso. No es el puerto de la interfaz de este entorno.
