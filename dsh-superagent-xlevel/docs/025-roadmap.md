# Hoja de ruta

Nivel 1 — fundación arquitectónica. Lo marcado como referencia funciona en local y no simula un proveedor externo.

## Niveles

Nivel 1, este repositorio: contratos, roles, políticas, grafo, sandbox virtual, verificación, SQLite, CLI, API y pruebas.

Nivel 2: workers de sistema, probe real de modelos, cliente MCP, índice vectorial opcional.

Nivel 3: proyectos largos con equipos de agentes y evaluación continua. No está implementado y no se debe anunciar como tal.

## Orden

Nivel 1 está cerrado en local: contratos, política, perfiles, ciclo y pruebas. Nivel 2 es probe de Ollama, cliente MCP y worktrees, más leer la política desde JSON sin romper la frontera de `public.ts`. Nivel 3, equipos sostenidos, no está empezado.

Nada de ese orden pide desactivar salvaguardas ni marcar un proveedor como verificado por adelantado.
