# MCP

Nivel 1 — fundación arquitectónica. Lo marcado como referencia funciona en local y no simula un proveedor externo.

## Contrato externo

MCP se trata como protocolo versionado, no como un dialecto propio. Un manifiesto MCP se normaliza a ToolManifest: id, inputSchema, permisos y ejecución.

Este scaffolding no abre un servidor MCP ni descarga el SDK en el arranque. El normalizador y el esquema están listos para un adaptador que sí hable el protocolo.

## Qué hay y qué no

El contrato `ToolManifest.source.type` admite `mcp`. No hay un cliente conectado ni un servidor levantado. Un manifiesto MCP no recibe `verified: true` por existir el enum.

Hasta el nivel 2, una herramienta que no esté en `config/tools/native.json` no se ejecuta. El runtime responde `unknown_tool`.
