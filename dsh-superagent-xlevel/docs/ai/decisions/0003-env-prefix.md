# 0003 — SMITH_* es el prefijo, DSH_* el alias

Fecha: 2026-11-07. Estado: vigente.

El producto se llama Sr.Smith. `SMITH_MODE`, `SMITH_PROFILE`, `SMITH_DATA_DIR`, `SMITH_HOST` y `SMITH_PORT` ganan a `DSH_*` si las dos están definidas. El alias se mantiene para no romper checkpoints ni scripts ya escritos.

No se documenta una variable de clave como activa hasta que un adaptador la lea.
